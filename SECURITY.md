# Security Policy

If you believe you have found a security vulnerability, please report it privately.

Our preference is that you use GitHub's private vulnerability reporting flow for this repository.

To do this:

1. Open the repository on GitHub.
2. Go to the Security tab.
3. Click `Report a vulnerability`.

Please do not open public issues for security-sensitive reports.

We will investigate legitimate reports and do our best to address confirmed issues promptly.
