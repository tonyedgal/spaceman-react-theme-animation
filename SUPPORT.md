# Support

## Getting Help

Use GitHub issues for bugs, regressions, and documentation problems.

When opening an issue, include:

- the package version
- your framework and version
- a minimal reproduction or code sample
- expected behavior
- actual behavior
- screenshots or terminal output if relevant

## Before Opening An Issue

Please check:

- the package README: `packages/react-theme-animation/README.md`
- the framework guides in `packages/react-theme-animation/docs/`
- the example apps in `apps/examples/`
- `MIGRATION.md` if you are updating from older import paths

## Security

Do not report security issues in public GitHub issues.

Follow `SECURITY.md` for private vulnerability reporting.
